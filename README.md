# AITravelPlanner-
Travel Planning agentic system
## how to run
1. Create the virtual env
```bash
conda create - n travel python=3.11 -y
```
2. Activate the env
```bash
conda activate travel
```

3. Install the requirement file
```bash
pip install -r requirements.txt
```
